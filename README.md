# 🌻 洛克王国：世界 - 自动挂机助手 Pro (Roco Kingdom Macro)

一款专为《洛克王国：世界》（WeGame端/PC端）打造的高级自动化挂机脚本。基于 Python 编写，采用底层 `PostMessage` 句柄注入技术与极致的拟真防封逻辑，解放你的双手！

## ✨ 核心特性

- 🛡️ **防封逻辑**：内置动态随机延迟、按键粘滞模拟、随机 AFK（真人发呆）机制，最大程度规避 TP 反作弊检测。
- 👻 **双模式自由切换**：
  - **刷花模式**：纯后台运行（支持窗口最小化或被遮挡），自动循环 `Tab -> 2(鞠躬) -> Esc -> Space`。
  - **刷鬼火模式**：后台长按 `W` 键配合物理鼠标平滑转向，实现原地无限绕圈刷怪。
- 🎯 **精准进程锁定**：通过 `psutil` 配合底层 API，精准锁定 `NRC-Win64-Shipping.exe` 进程句柄，绝不误操作其他窗口。
- 🖥️ **可视化 GUI 界面**：自带轻量级悬浮操作面板与实时运行日志，告别黑框框，支持 `F9` 全局热键一键秒启/秒停。
- 🧩 **模块化架构**：核心引擎、配置管理与 UI 界面完全解耦，极易二次开发与功能扩展。

## 🚀 环境依赖与运行

### 1. 环境要求

- Windows 10 / 11 操作系统
- Python 3.8 或更高版本

### 2. 安装依赖库

在项目根目录下打开终端（CMD / PowerShell），运行以下命令安装必需的第三方库：

Bash

```
pip install pypiwin32 psutil keyboard
```

*(注：GUI 界面使用了 Python 内置的 `tkinter`，无需额外安装。)*

### 3. 运行脚本

由于使用了全局键盘监听（`keyboard`）和底层系统 API，**必须以管理员身份运行**：

- 右键点击终端图标 -> 以管理员身份运行。

- 在终端中执行：

  Bash

  ```
  python main.py
  ```

## ⚙️ 参数配置 (config.py)

如果您觉得动作太快/太慢，或者想要修改按键，可以打开 `config.py` 进行傻瓜式修改：

- `KEY_PRESS_DURATION`: 按键按下的持续时间（默认 80~120ms）
- `BOW_WAIT`: 刷花模式中，鞠躬动作的等待时间（默认 14.5秒 ~ 15.5秒）
- `GHOST_FIRE_MOUSE_SPEED`: 刷鬼火时的鼠标转向速度（负数向左，正数向右）
- `AFK_CHANCE` / `REST_CHANCE`: 触发防封发呆休息的概率

## 📦 编译为独立 EXE (分享给他人)

如果您想将脚本分享给没有安装 Python 环境的朋友使用，可以通过 `PyInstaller` 将其打包为单文件 `.exe`。

1. 安装打包工具：

   Bash

   ```
   pip install pyinstaller
   ```

2. 在项目根目录下执行以下打包命令：

   Bash

   ```
   pyinstaller -F -w --uac-admin main.py
   ```

   - `-F`：打包为单个 exe 文件。
   - `-w`：隐藏黑色控制台窗口。
   - `--uac-admin`：**强制申请管理员权限（挂机脚本必须配置）**。

3. 打包完成后，进入新生成的 `dist` 文件夹，提取 `main.exe` 即可直接双击使用。

## ⚠️ 常见问题与注意事项

1. **杀毒软件误报（非常重要）** 由于脚本使用了 `keyboard` 全局热键拦截以及 `PostMessage` 内存消息注入技术，打包成 `.exe` 后极易被 360、Windows Defender 等杀毒软件误判为木马病毒。**这是正常的假阳性误报**，请添加至信任白名单后使用。
2. **刷鬼火模式鼠标被占用** “刷鬼火”模式涉及 3D 视角的平滑转动，必须调用物理鼠标接口（相对位移）。在此模式运行期间，**请勿强行抢夺物理鼠标的控制权**，否则会导致视角混乱。如需操作电脑，请先按 `F9` 暂停脚本。
