# 🌻 洛克王国：世界 - 自动挂机助手 (Roco Kingdom Macro)

《洛克王国：世界》（WeGame/PC端）自动化辅助工具。基于 Python 开发，配合轻量级 GUI 可视化面板，彻底解放你的双手。

## ✨ 核心特性

- 🎮 **双模式自由切换**：
  - **🌺 刷花模式 (纯后台)**：自动循环 `Tab 锁定 -> 2 鞠躬 -> Esc 取消 -> Space 跳跃`。支持将游戏窗口最小化或被遮挡，完全不影响你使用电脑做其他事情。
  - **🔥 刷鬼火模式 (半前台)**：后台长按 `W` 键前进，配合物理鼠标底层的平滑左转偏移，实现原地无限绕圈刷火。
- 🛡️ **防封逻辑**：摒弃死板的固定延迟。内置切片随机延迟 (`SafeSleep`)、按键粘滞模拟、以及随机触发的 AFK和轮次休息机制，最大程度规避 TP 反作弊检测。
- 🎯 **精准进程侦测**：通过 `psutil` 配合 Windows 底层 API，基于进程名 `NRC-Win64-Shipping.exe` 绝对精准锁定游戏主句柄，拒绝误操作。
- 🖥️ **可视化 UI 面板**：告别命令行黑框！提供美观的悬浮操作面板、实时动作日志输出，支持 `F9` 全局热键一键秒启/秒停。

## 🚀 快速上手

### 1. 环境准备

- Windows 10 / 11 操作系统
- Python 3.8 或更高版本

### 2. 安装依赖库

在项目根目录下打开终端（CMD / PowerShell），运行以下命令安装必需的第三方库：

Bash

```
pip install pypiwin32 psutil keyboard
```

*(注：GUI 界面使用了 Python 内置的 `tkinter`，无需额外安装。)*

### 3. 运行助手

由于脚本使用了全局键盘监听（`keyboard`）和底层系统 API，**必须以管理员身份运行**：

- 右键点击终端图标 -> 以管理员身份运行。

- 在项目目录中执行：

  Bash

  ```
  python main.py
  ```

## ⚙️ 高级参数配置 (config.py)

如果您想自定义脚本的运行节奏，只需用记事本或代码编辑器打开 `config.py`：

- `KEY_PRESS_DURATION`: 按键按下的持续时间（默认 `80~120ms` 随机波动，模拟真人肉体粘滞感）。
- `BOW_WAIT`: 刷花模式中，鞠躬动作的等待时间（默认 `14500~15500ms`，即约 15 秒）。
- `GHOST_FIRE_MOUSE_SPEED`: 刷鬼火时的鼠标转向速度（默认 `-5`，负数向左，正数向右，绝对值越大转得越快）。
- `AFK_CHANCE`: 每轮动作开始前，模拟真人发呆 10~20 秒的概率（默认 `0.03` 即 3%）。

## 📦 打包为独立 EXE (分发给他人使用)

如果您想将工具分享给没有安装 Python 环境的朋友，可以使用 `PyInstaller` 将其打包为无需安装环境、双击即用的单文件 `.exe`。

1. 安装打包工具：

   Bash

   ```
   pip install pyinstaller
   ```

2. 在项目根目录下执行以下打包命令：

   Bash

   ```
   pyinstaller -F -w --uac-admin main.py
   ```

   - `-F`：打包整合为单个 exe 文件。
   - `-w`：隐藏黑色控制台背景窗口。
   - `--uac-admin`：**赋予程序 UAC 管理员权限清单。

3. 打包完成后，进入新生成的 `dist` 文件夹，将里面的 `main.exe`发送给朋友即可。

## ⚠️ 常见问题与免责声明

1. **杀毒软件误报拦截（必读）** 因脚本使用了 `keyboard` 模块进行全局热键（F9）拦截，以及调用了 `PostMessage` 进行内存消息注入。在打包为 `.exe` 后，极大概率会被 360、火绒或 Windows Defender 误判为木马病毒。**这是自动化脚本的正常现象**，请在运行前将其添加至杀毒软件信任白名单。
2. **刷鬼火模式的使用限制** “刷鬼火”模式涉及 3D 视角的平滑转动，必须强制调用当前系统的物理鼠标进行相对位移。在该模式运行期间，**请勿强行滑动或抢夺物理鼠标的控制权**，否则会导致游戏视角混乱。如需操作电脑，请先按 `F9` 暂停脚本。
